## Structure

- `index.html` — page unique : contenu, styles intégrés, aucun JavaScript

Aucun framework ni étape de build : HTML et CSS uniquement. Seules les
polices (Source Serif 4, Source Sans 3) sont chargées depuis Google Fonts.

## Lancer en local

```bash
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000.

## Déploiement

Le site est servi par GitHub Pages depuis la branche `main` (racine du
dépôt). Tout push sur `main` met à jour le site automatiquement.
